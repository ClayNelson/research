# AI + ARM + Agentic Signals

This repo is a working log of twice-weekly research scans across LinkedIn, X, and the broader web, focused on:

1. **ARM-native compute & cloud migration**
   - Graviton, Cobalt, Apple M-series, on-device AI, edge workloads
2. **Edge AI & hardware–software co-design**
   - AI on chip, silicon + tooling convergence, inference at the edge
3. **AI agents & MCP-style orchestration**
   - GitHub as Agent HQ, multi-agent workflows, PRU-based consumption
4. **Regulated developer experience**
   - Automotive, IoT/embedded, industrial, medical, safety-critical workflows
5. **AI-native organizational design & complexity reduction**
   - How orgs adapt structure, roles, and process to AI-native work

Twice a week, a research scan is run and saved here as a dated note under `/runs`. Each note contains:

- A **synthesis** of key developments since the last scan  
- An **adversarial critique** of my current theses  
- **Updated or refined hypotheses** and open questions  

The goal isn’t to be “right” in static form, but to increase the *resolution* of my mental model over time, using the outside world as a continuous, structured challenge.

---

## Workflow

1. **Capture**  
   - Each scan is written as `YYYY-MM-DD-[dow].md` in `/runs`.

2. **Reflect**  
   - After reading a scan, I update `/theses/2025-11-16-standing-theses.md`
     with any changes in my beliefs, confidence levels, or framing.

3. **Extract questions**  
   - Any big “huh?” moments go into `/questions/open-questions.md`.

4. **Define experiments**  
   - When a signal suggests a testable move (deck, customer convo, partner
     question, slide for Mario/Elizabeth, etc.), it goes into `/questions/experiments.md`
     with a status (planned, running, completed).

Over time, this repo should reflect not just *what* I believe about AI, ARM,
and agentic platforms, but *how* those beliefs were stress-tested and updated.
